### Key topics covered
- **Concepts:** Zero Trust (verify explicitly / least privilege / assume breach), CIA triad, defense-in-depth layers, shared responsibility model (IaaS/PaaS/SaaS), common threat types (phishing, MitM), encryption at rest vs in transit
- **Entra ID:** What is Entra ID, MFA, SSPR, passwordless (FIDO2, Windows Hello), SSO, managed identity vs service principal, B2B vs B2C, Conditional Access, PIM (just-in-time), Identity Protection (risk detections), Access Reviews, Entra Connect hybrid sync, P1/P2 licensing, Entra Verified ID
- **Security solutions:** Defender for Cloud (CSPM + CWP, Secure Score, JIT VM access), Defender for Endpoint (EDR), Defender for Office 365 (Safe Links/Attachments), Defender for Cloud Apps (CASB), Defender for Identity (on-prem AD attacks), Defender XDR portal, Microsoft Sentinel (SIEM: data connectors; SOAR: playbooks; hunting; analytics rules; workbooks), Azure Key Vault (secrets vs keys vs certs), Azure Firewall vs NSG, WAF vs DDoS Protection, Azure Bastion, Intune MDM/MAM + Conditional Access device compliance
- **Compliance:** Microsoft Purview overview, Compliance Manager + compliance score, sensitivity labels, DLP policies, retention policies/labels, Insider Risk Management, Purview Audit (Standard vs Premium), eDiscovery (Standard vs Premium, legal hold), Communication Compliance, Information Barriers, Microsoft Priva (Subject Rights Requests)
