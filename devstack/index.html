🧱 DevStack

Le tech stack des grandes boîtes IT

Compilé depuis leur blog ingénierie, job postings publics et GitHub. Chaque composant a une source citée. Les stacks bougent — chaque dossier affiche sa date de revue.

🔍 Search-as-a-Service — API de recherche performante
Algolia
Référence française du Search-as-a-Service. Moteur core écrit en C++ pour la performance (sub-100ms), API publique en Go, dashboards en TypeScript/React. Infrastructure 100+ datacenters dédiés (DSN — Distributed Search Network).

🚗 Covoiturage & bus longue distance
BlaBlaCar
Plateforme française de covoiturage née en 2006. Backend historiquement PHP/Symfony, étendu en Go pour les services exigeants ; mobile unifié sur React Native ; migration cloud vers Google Cloud avec Kafka pour l'événementiel.
10 composants · Révisé 2026-05
🌐 Réseau edge, sécurité & plateforme de calcul (CDN, WAF, Workers)
Cloudflare
Réseau edge mondial bâti sur du Rust à forte dose (proxy Pingora) et du Go, avec une plateforme de calcul Workers fondée sur des isolats V8 plutôt que des conteneurs. L'un des blogs d'ingénierie les plus prolifiques du secteur.
10 composants · Révisé 2026-05
🐶 Observabilité & monitoring cloud (SaaS)
Datadog
Plateforme d'observabilité SaaS fondée en 2010 par deux ingénieurs (dont le Français Olivier Pomel). Backend massivement en Go et Python, l'un des plus gros opérateurs de Kafka au monde, infrastructure multi-cloud à très grande échelle.
11 composants · Révisé 2026-05
🏥 HealthTech — plateforme de prise de rendez-vous + télémédecine
Doctolib
Plateforme healthtech la plus utilisée d'Europe. Stack Rails + React resté volontairement simple, avec un focus très fort sur compliance (hébergement HDS), perf et fiabilité plutôt que sur la diversité technologique.
8 composants · Révisé 2026-05
🦊 Plateforme DevOps tout-en-un (SaaS + self-managed)
GitLab
Plateforme DevOps qui assume publiquement un monolithe Ruby on Rails, entouré de services Go (Gitaly, Workhorse, Runner). Entreprise 100% distribuée dont le handbook d'ingénierie est entièrement public.
11 composants · Révisé 2026-05
🔨 Marketplace bricolage, maison & jardin
ManoMano
Marketplace française du bricolage née en 2013. Stack partie d'un monolithe PHP/Symfony, décomposée progressivement en services polyglottes (Scala, Kotlin, Python) sur Google Cloud, avec Kafka comme colonne vertébrale événementielle.
12 composants · Révisé 2026-05
🎬 Streaming vidéo (SVOD), production de contenu
Netflix
Référence mondiale de l'infrastructure cloud à grande échelle. Stack JVM dominant, AWS-natif depuis 2008 (la fameuse migration historique), avec un CDN propriétaire Open Connect et une culture chaos engineering qu'ils ont inventée. Énorme contribution open-source (Spinnaker, Hystrix, Atlas, Zuul…).
12 composants · Révisé 2026-05
💳 Fintech / Néobanque globale
Revolut
Néobanque britannique scalée à 45M clients en moins de 10 ans. Stack JVM dominant (Java, Kotlin), microservices sur Kubernetes, Kafka événementiel, PostgreSQL — avec une discipline anti-monolithe poussée loin et une approche multi-cloud.
10 composants · Révisé 2026-05
🎵 Streaming audio / podcast / vidéo musicale
Spotify
Stack massivement polyglotte JVM (Java, Scala), avec Backstage (leur portail développeur interne open-sourcé) devenu standard CNCF. Infrastructure majoritairement Google Cloud, microservices à l'échelle (~2000+ services). Le 'Backend@Spotify' blog est l'une des références les plus citées de l'industrie.
13 composants · Révisé 2026-05
💳 Fintech — infrastructure paiements pour Internet
Stripe
Le standard de facto de l'infrastructure paiements internet. Stack Ruby + Java + Go historiquement, avec une discipline opérationnelle financière obsessionnelle : test coverage maniaque, observabilité maison (Veneur, Sorbet pour typer Ruby), revues SRE strictes.
10 composants · Révisé 2026-05
🛍️ C2C Marketplace (mode, seconde main)
Vinted
Marketplace seconde main née en Lituanie en 2008, devenue licorne européenne. Stack historiquement Rails, en migration progressive vers une plateforme polyglotte (Go, Kotlin) avec Kafka comme épine dorsale événementielle.
