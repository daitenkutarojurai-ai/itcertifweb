🏛️ Culture ingénierie

Stack volontairement conservatif et resserré : Rails + React + Postgres, fait simple, exécuté correctement. Compliance HDS (Hébergement de Données de Santé) et RGPD imposent une discipline opérationnelle plus que d'innovation tech permanente. Forte présence d'ingénieurs sur le blog Medium parlant performance, sécurité, qualité de code.

👋 Recrutement

Recrutement très actif Paris et Berlin. Stack annoncé clairement dans les offres — pas de bullshit 'rockstar full-stack', les rôles backend / frontend / SRE sont bien séparés.
