🔍 Détail outil par outil

Obsidian + Copilot plugin

Obsidian + community

Notes locales en markdown + plugin Copilot qui plug n'importe quel LLM (OpenAI, Anthropic, Ollama local).

Obsidian gratuit (perso) · Copilot plugin gratuit (BYOK API)[pricing officiel]
Pros
  • 100% local : tes notes sont des .md dans un dossier, point. [source]
  • Mode 100% offline avec Ollama — aucune donnée ne quitte ta machine.
  • Le meilleur écosystème plugins de la catégorie (>1500 plugins). [source]
Cons
  • BYOK API : tu paies la consommation au provider (Anthropic / OpenAI / etc.).
  • Setup initial moins user-friendly que Notion — il faut configurer les plugins.
Best for —Quiconque a une contrainte privacy + veut un système de notes qui durera 20 ans.

Reflect

Reflect Notes

Notes daily-journal + bidirectional links + AI assistant E2E chiffré.

$10/mo (annuel) · pas de free tier[pricing officiel]
Pros
  • End-to-end encrypted by default — Reflect ne peut pas lire tes notes. [source]
  • AI assistant GPT-4/Claude-class inclus dans le tarif, pas un add-on.
  • UX clean et opinionnée (daily notes + backlinks).
Cons
  • Pas de free tier — barrier-to-try plus haute que Notion ou Obsidian.
  • Pas de mode local : les notes vivent dans le cloud chiffré Reflect (clés chez toi).
Best for —Devs / writers qui aiment le format Roam/Logseq + veulent du chiffrement E2E.
→ Try Reflect

Mem

Mem.ai

App de notes 'AI-first' : tout est lié automatiquement, chat avec ta knowledge base.

Free (limité) · Mem AI $14.99/mo (annuel) ou $19.99/mo[pricing officiel]
Pros
  • AI search natif et fluide : 'Que m'a dit X la semaine dernière sur Y ?' marche bien.
  • Auto-tagging et auto-linking — pas besoin de maintenir un graph à la main.
Cons
  • Cloud-only : tes notes sont chez Mem, pas chez toi.
  • Écosystème plugins inexistant — c'est l'app, tu t'adaptes.
  • Tarif relativement élevé pour l'AI sans alternative gratuite vraiment usable.
Best for —Knowledge workers qui veulent une assistante AI conversationnelle et ne veulent pas configurer.
→ Try Mem

Tana

Tana

Notes 'supertags' (chaque node a un type/schéma) + AI commands.

Free (limité) · Pro $14/mo[pricing officiel]
Pros
  • Modèle 'supertag' puissant : chaque node a un schéma, donc structures évolutives sans rigidité Notion.
  • AI commands natives (résumer, transformer, créer un task de cette note).
Cons
  • Cloud-only, encore.
  • Courbe d'apprentissage initiale plus forte que Notion (concept supertag à digérer).
Best for —Power-users Notion qui se sentent à l'étroit dans les databases Notion.
→ Try Tana

Coda AI

Coda

Docs hybride doc / spreadsheet / app builder + AI Maker block.

Free (Doc Maker $12/mo) · AI add-on $12/mo[pricing officiel]
Pros
  • AI blocks programmables — tu peux scripter l'AI dans un doc comme une fonction. [source]
  • Bon écosystème 'packs' (intégrations Slack, Jira, Gmail…).
Cons
  • Pricing à plusieurs étages compliqué (Maker + AI add-on).
  • Pas de stockage local. Cloud-only.
Best for —Équipes qui veulent un Notion-killer avec spreadsheet + automation AI.
→ Try Coda
