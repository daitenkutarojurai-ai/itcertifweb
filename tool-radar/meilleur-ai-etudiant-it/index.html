🔍 Détail outil par outil

Claude.ai (Free)

Anthropic

Claude Sonnet en accès gratuit avec quota quotidien, app mobile iOS/Android.

Free (quota quotidien Sonnet) · Pro $20/mo (Opus + plus de quota)[pricing officiel]
Pros
  • Claude Sonnet est top du classement code en 2026 (LiveCodeBench, SWE-Bench Verified). [source]
  • Le modèle qui explique le mieux step-by-step — utile en mode 'apprends-moi X'.
  • App mobile fluide avec voice mode et image input.
Cons
  • Quota free atteint vite si tu lui demandes de longues réponses ou plusieurs fichiers.
  • Pas de citations sourcées (sauf en mode web search activé).
Best for —Étudiant dev qui veut le meilleur tuteur code gratuit + assistant de raisonnement.
→ Try Claude

Gemini (Free)

Google

Gemini Flash gratuit + intégration Google Workspace, app Android excellente.

Free (Gemini Flash) · Advanced $20/mo (Gemini Pro Ultra + Drive intégré)[pricing officiel]
Pros
  • Free tier Gemini Flash très généreux, pas de hard quota pour usage normal.
  • Intégration native Google Drive / Docs / Gmail — utile si tes notes sont dans Google Workspace.
  • App Android exceptionnelle (substitue Google Assistant).
Cons
  • Gemini Flash code est en retrait vs Claude Sonnet / GPT-5 sur les benchmarks.
  • Pour le meilleur modèle (Gemini Pro Ultra) il faut Advanced à $20/mo.
Best for —Étudiant Android + workspace Google qui veut un assistant gratuit ambient.
→ Try Gemini

ChatGPT (Free)

OpenAI

GPT en accès gratuit, app mobile très polie, écosystème GPTs partagés.

Free (modèle gratuit limité) · Plus $20/mo (GPT-5 + plus de quota) · Pro $200/mo[pricing officiel]
Pros
  • L'app mobile la plus polie : voice 'Advanced' inclus partiellement en free. [source]
  • GPTs partagés permettent d'utiliser des assistants spécialisés sans config.
  • Connu de tous tes profs et copains de promo — base commune utile pour les groupes d'étude.
Cons
  • Free tier limité au modèle 'mini' en 2026 — GPT-5 réservé à Plus.
  • Hallucinations sur les questions niches (RFC réseau, exam-specific topics).
Best for —Étudiant qui veut une expérience mobile premium gratuite et l'écosystème GPTs.
→ Try ChatGPT

Phind

Phind

Moteur de recherche AI spécialisé dev — résultats code + sources cliquables.

Free (limité) · Pro $20/mo (modèles plus performants, plus de searches)[pricing officiel]
Pros
  • Sources systématiquement citées et cliquables — top pour vérifier ce qu'il raconte. [source]
  • Optimisé pour les questions dev : 'pourquoi mon docker compose part en boucle' = réponse code-friendly directe.
  • Free tier suffisant pour usage étudiant occasionnel.
Cons
  • Pas d'app mobile native — usage desktop principalement.
  • Moins bon que les généralistes (Claude/GPT) sur des tâches non-dev (writing, math).
Best for —Étudiant dev qui passe sa journée à débugger et veut un Stack Overflow turbocompressé.
→ Try Phind

You.com

You.com

Recherche AI multi-modes (Smart, Genius, Research) + cite sources, choix de modèle.

Free (limité) · Pro $20/mo · Business $25/u/mo[pricing officiel]
Pros
  • Mode 'Research' fait des rapports multi-sources, utile pour les dossiers d'études.
  • Toggle entre Claude, GPT, Gemini, Llama dans la même UI (Pro).
  • Citations toujours présentes (différence majeure vs ChatGPT free).
Cons
  • Free tier plus restrictif que Claude / Gemini.
  • Pas le go-to pour du code pur : Phind est plus spécialisé.
Best for —Étudiant en filière universitaire (recherche docs, citations académiques) plutôt que dev pur.
→ Try You.com
