Pour qui chacune ?

AWS Certified Cloud Practitioner

Amazon AWS · CLF-C02
Tu débutes totalement dans le cloud, ou tu es dans un rôle non-technique (commercial, chef de projet, finance) chez un éditeur cloud-adjacent.
  • Aucun prérequis, conçue pour les débutants : tu peux la passer même sans jamais avoir ouvert la console AWS.
  • Prep réaliste de 40-60h — environ 4-6 semaines à temps partiel, contre 3-4 mois pour la SAA.
  • Examen le moins cher de la gamme AWS (100$) : faible coût pour valider que le cloud te plaît.
  • Couvre le vocabulaire transverse (régions, IAM, modèle de responsabilité partagée, facturation) utile à tout rôle, technique ou non.
  • Signal CV faible seule pour un poste technique : un recruteur Cloud Engineer attend la SAA, pas la CLF.
  • Zéro profondeur architecturale — pas de design de VPC, pas de dimensionnement, pas de scénarios de panne.
  • Souvent perçue comme une 'cert d'échauffement' : rarement suffisante pour décrocher un premier poste cloud à elle seule.

AWS Solutions Architect Associate

Amazon AWS · SAA-C03
Tu as déjà un background tech (dev, sysadmin, ops, support N2/N3) et tu veux le diplôme qui débloque concrètement les postes cloud.
  • La cert cloud de référence sur le marché français : c'est celle que les recruteurs citent dans les offres Cloud Engineer / Architect.
  • Salaire médian senior 65k€ en France contre 52k€ pour un profil arrêté à la CLF (estimations indicatives).
  • Teste du vrai design : VPC, dimensionnement, haute dispo multi-AZ, choix de service, optimisation de coût.
  • Ouvre directement la suite associate/pro (Developer, SysOps, puis Solutions Architect Professional).
  • Examen technique : difficile à viser directement si tu n'as jamais administré d'infra ni manipulé AWS.
  • Prep réaliste de 120-150h — compte 3 à 4 mois à raison de 8-10h/semaine.
  • 150$ l'examen, et un échec coûte cher en temps : mieux vaut arriver prêt.
