Who is each one for?

AWS Certified Cloud Practitioner

Amazon AWS · CLF-C02
You are completely new to cloud, or you work in a non-technical role (sales, project management, finance) at a cloud-adjacent company.
  • No prerequisites and built for beginners: you can pass it without ever having opened the AWS console.
  • Realistic prep of 40-60 hours — roughly 4-6 weeks part-time, versus 3-4 months for the SAA.
  • The cheapest exam in the AWS lineup ($100): a low-cost way to confirm you actually enjoy cloud work.
  • Covers the cross-cutting vocabulary (Regions, IAM, the shared responsibility model, billing) that every role needs, technical or not.
  • Weak résumé signal on its own for a technical role: a Cloud Engineer recruiter expects the SAA, not the CLF.
  • Zero architectural depth — no VPC design, no sizing, no failure scenarios.
  • Often seen as a 'warm-up cert': rarely enough on its own to land a first cloud job.

AWS Solutions Architect Associate

Amazon AWS · SAA-C03
You already have a tech background (developer, sysadmin, ops, tier-2/3 support) and want the credential that actually unlocks cloud jobs.
  • The reference cloud cert on the job market: it is the one recruiters name in Cloud Engineer / Architect job postings.
  • Senior median salary of €65k in France versus €52k for a profile that stopped at the CLF (indicative estimates).
  • Tests real design: VPCs, sizing, multi-AZ high availability, service selection, cost optimization.
  • Leads straight into the rest of the Associate/Pro track (Developer, SysOps, then Solutions Architect Professional).
  • A technical exam: hard to target directly if you have never administered infrastructure or used AWS.
  • Realistic prep of 120-150 hours — plan for 3-4 months at 8-10 hours per week.
  • $150 per attempt, and a fail is expensive in time: better to show up ready.
