Pour qui chacune ?

Google Cloud Associate Cloud Engineer

Google Cloud · ACE
Tu cibles des boîtes cloud-native, des startups SaaS ou des clients dans la data/ML. Tu veux te démarquer dans un marché moins saturé que AWS.
  • Moins de candidats = moins de compétition — un profil GCP certifié se distingue plus facilement sur le marché FR.
  • Focus IAM + Kubernetes (GKE) très valorisé dans les boîtes cloud-native et startups SaaS.
  • 200$ seulement — le moins cher des exams cloud associate (AWS SAA = 300$).
  • BigQuery, Vertex AI, GKE — positionnement data & ML plus affirmé qu'Azure ou AWS.
  • Marché plus restreint en France que AWS — les offres GCP représentent ~15-20% des offres cloud FR vs ~50% pour AWS.
  • Moins de ressources gratuites de prep que AWS (moins de Udemy/YouTube GCP que AWS).
  • L'examen est réputé plus difficile que le AWS CLF mais comparé au SAA-C03, les avis divergent.

AWS Solutions Architect Associate (SAA-C03)

Amazon Web Services · SAA-C03
Tu cherches ton premier CDI cloud, tu veux la cert la plus reconnue, ou tu cibles ESN / grands comptes qui tournent majoritairement sur AWS.
  • Cert cloud #1 mondiale — le plus grand vivier d'offres d'emploi, en France et partout en Europe.
  • Signal fort sur CV : recruteurs IT connaissent la SAA-C03, pas toujours la GCP ACE.
  • Huge ressources de prep : Andrew Brown, Stephane Maarek, TutorialsDojo — niveau d'accompagnement imbattable.
  • AWS détient ~33% du marché cloud mondial — probabilité élevée de trouver AWS dans la stack de ton prochain employeur.
  • 300$ pour l'examen — 50% plus cher que la GCP ACE.
  • Marché plus saturé : beaucoup de profils AWS → différenciation plus difficile à niveau équivalent.
  • Architecture AWS (VPC, IAM, EC2, S3, RDS, etc.) + pricing = scope large, ~80-120h de préparation réaliste.

GCP hérite du monde Linux/GKE : IAM orienté resource, Compute Engine proche du baremetal, GKE natif. La transition est plus fluide que AWS si tu viens d'un background ops Linux.
