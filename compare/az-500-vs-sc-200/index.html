AZ-500 vs SC-200: Cloud Security or SOC Analyst?
Microsoft's two most in-demand security certs. Not the same job, not the same workday.

A straight, no-fluff comparison — decide in 5 minutes which one fits your profile.

Reviewed 2026-07 2 certifications 9 profiles analyzed
TL;DRAZ-500 = the engineer who BUILDS Azure security (IAM, networking, Key Vault, Defender for Cloud). SC-200 = the analyst who OPERATES security in the SOC (Defender XDR + Sentinel + KQL). Same vendor, two jobs. Median salary in France is higher for the AZ-500 (Cloud Security Engineer, €70k+ senior) than the SC-200 (Microsoft SOC analyst, €45-60k mid). Choose by what you do every day: do you deploy, or do you investigate?

Who is each one for?

Azure Security Engineer Associate (AZ-500)

Microsoft Azure · AZ-500
You're an Azure Admin / DevOps / Cloud Engineer and want to add security to your scope. You're targeting Cloud Security Engineer / Cloud Security Architect roles at an Azure end client, a scale-up or a Microsoft Solutions Partner integrator.
  • A cloud engineer's cert: IAM (Entra ID, Conditional Access, PIM), network protection (NSG, Azure Firewall, WAF, DDoS Standard), data protection (Key Vault, Storage encryption, Purview), Defender for Cloud + posture — the daily work of a Cloud Security Engineer who BUILDS security into Azure.
  • Sought after by scale-ups and IT departments migrating to Azure: a very active market for 'Azure Security Engineer / Cloud Security Engineer' postings in 2026 (often €60-85k in France for an experienced AZ-104 + AZ-500 profile).
  • Recognition reinforced by Microsoft's 2024 Learn/Certifications overhaul: a clear AZ-900 → AZ-104 → AZ-500 path (then SC-100 Cybersecurity Architect Expert if you're aiming for architect).
  • 40-60 questions in 100 minutes, available in several languages, with case studies and sometimes Azure Portal configuration labs — it genuinely assesses hands-on skill, not just multiple choice.
  • Assumes a solid Azure foundation: without AZ-104-level knowledge (VNet, RBAC, Storage, App Service, PowerShell/CLI), the exam becomes a wall — Microsoft effectively treats it as an unofficial prerequisite.
  • 100% Azure scope: if your security stack centers on Microsoft 365 (Exchange Online, Teams, Defender for Office/Endpoint), about 40% of the AZ-500 content has no daily application.
  • Ages quickly: Entra ID renamed (formerly Azure AD), Defender for Cloud restructured, Sentinel 'unified' into the Defender XDR portal in 2024 — each Microsoft refresh can change 15-20% of the content.
  • An 'Associate' cert — the senior signal comes from the SC-100 (Expert) above it, not from the AZ-500 alone. Senior Cloud Security Architects often hold AZ-500 + SC-100 + a second cloud family (AWS or GCP).

Microsoft Security Operations Analyst Associate (SC-200)

Microsoft Azure · SC-200
You work in (or are targeting) a Microsoft-shop SOC / CSIRT, an MSSP, or the blue team of a large enterprise that moved to Defender XDR + Sentinel. You operate security day to day; you don't build it.
  • A SOC analyst / blue team cert: Microsoft Defender XDR (Endpoint, Identity, Office 365, Cloud Apps), Microsoft Sentinel (KQL, workbooks, Logic Apps playbooks, analytics rules, threat hunting), end-to-end incident management and investigation — it matches the daily work of a tier-1/tier-2 analyst in a Microsoft-shop SOC.
  • No hard Azure prerequisite: the cert targets the security analyst, not the cloud engineer. A SOC analyst coming from another SIEM (Splunk, QRadar) can pass it with 60-100 hours of prep without ever having provisioned an Azure VM.
  • The managed SOC market (MSSPs such as Orange Cyberdefense, Advens, I-Tracing, Sopra Steria, Almond) keeps growing since NIS2 and the ransomware surge on SMBs — the SC-200 is explicitly listed in these MSSPs' 'Microsoft SOC Analyst' job descriptions in 2026.
  • The best effort-to-value ratio if your company has already deployed Defender for Endpoint + Sentinel: the cert immediately validates 100% of your workday, unlike SIEM-agnostic certs (GCIH, GCFA, etc.) that stay more general.
  • 100% Microsoft scope: if your company uses CrowdStrike Falcon, Splunk, SentinelOne or a multi-vendor stack, the SC-200 only validates the Defender/Sentinel subset — the fastest-changing part of the field.
  • A Microsoft 'Intermediate' level: lower salary recognition than the AZ-500 (in France, junior/mid SOC analysts often plateau at €45-60k, while AZ-500 Cloud Security Engineers pass €65-80k from 3-4 years of experience — Hays / APEC 2026).
  • KQL + Sentinel + Defender XDR content moves at Microsoft's sprint pace: the 2024 version differs significantly from 2022 (unified Defender portal, built-in threat hunter, MDCA renamed) — you must keep up with Microsoft Learn updates.
  • Does NOT replace real SOC experience: Microsoft sells the SC-200 as 'associate', but hiring an SC-200 analyst without field experience means a 3-6 month onboarding period for the employer.

The verdict, by profile

Not a ranking — each profile has a cert that fits it better. Find yours.

You build, deploy or administer Azure workloads (VMs, App Service, AKS, Storage) and need to secure them.
The AZ-500 is the engineer's manual: Network Security Groups, Azure Firewall, WAF, Key Vault, Managed Identities, Conditional Access, RBAC/PIM, Defender for Cloud posture. You learn to build security INTO the workloads you deploy. The SC-200 doesn't teach you how to secure an App Service — it teaches you how to investigate the incident when someone breaks into it.
Azure Security Engineer Associate (AZ-500)
You're a SOC / CSIRT / blue team analyst and your main SIEM is Microsoft Sentinel, or you already run Defender for Endpoint.
The SC-200 IS the Sentinel + Defender XDR analyst's manual: writing KQL rules, investigating MITRE ATT&CK alerts in the Defender portal, building Logic Apps playbooks, proactive threat hunting. It is literally the screen you'll sit in front of 8 hours a day — no need to pay for the AZ-500 for that.
Microsoft Security Operations Analyst Associate (SC-200)
You're an Azure Administrator (AZ-104 in hand) and want the natural next step into security without leaving engineering.
The AZ-500 is the next building block Microsoft officially recommends for the Azure Administrator / Security Engineer role. About 70% of the vocabulary (ARM/Bicep, RBAC, Networking, Storage) is already familiar — prep shrinks to 60-100 hours on the 5 security domains. Taking the SC-200 when you don't use Sentinel/Defender daily means studying 100% of the content from scratch.
Azure Security Engineer Associate (AZ-500)
You're new to security (moving from IT support / helpdesk / sysadmin) and want a first SOC analyst job in a Microsoft shop.
The SC-200 doesn't require a hard Azure background. The cert is recognized by MSSPs (Orange Cyberdefense, Advens, I-Tracing, Sopra Steria, Almond, XMCO) that hire tier-1/tier-2 analysts continuously. Pair it with the SC-900 (Security Fundamentals, free to prepare) to position yourself clearly as a 'junior Microsoft security' profile — around €40-45k entry level in France in 2026.
Microsoft Security Operations Analyst Associate (SC-200)
You're targeting a Cloud Security Architect role (Zurich Insurance, Sanofi, BNP Paribas, Talan, Sopra Steria consulting) paying €90-120k.
The AZ-500 is the Azure cloud architect's foundation. Microsoft's canonical path is AZ-500 (Associate) → SC-100 Cybersecurity Architect (Expert) — the SC-100 officially requires the AZ-500 (or an equivalent eligible cert). The SC-200 alone doesn't lead to an architect title: too operational, not enough design. Go AZ-500 then SC-100 for the Expert badge.
Azure Security Engineer Associate (AZ-500)
You want to become a Threat Hunter, senior Incident Responder or Detection Engineer in the Microsoft ecosystem.
The SC-200 covers exactly the Microsoft threat-hunting foundation: Advanced Hunting KQL on Defender XDR, Sentinel hunting queries, cross-source correlation, custom log ingestion. A senior Sentinel-native Detection Engineer commands €65-85k in France (Hays 2026, LinkedIn) and the market is tight. Then add GCIA / GCFA / SANS 511 to round out generic forensics/IR.
Microsoft Security Operations Analyst Associate (SC-200)
Your company uses neither Azure IaaS nor Microsoft Defender — it runs AWS + CrowdStrike + Splunk.
Rare but real: between the AZ-500 (100% Azure Portal, meaningless without Azure) and the SC-200 (Defender + Sentinel, applicable if you move to a future Microsoft-shop employer), the SC-200 at least has transferable blue-team value (KQL query patterns, MITRE ATT&CK mapping, incident triage). The AZ-500 at an AWS company = zero immediate return. Better still: take the AWS SCS-C02 or GIAC GCFA instead.
Microsoft Security Operations Analyst Associate (SC-200)
You want to maximize your median salary within 12 months.
In the 2026 French market, an AZ-104 + AZ-500 profile lands Cloud Security Engineer roles at €65-80k (senior, 3-5 years of experience) versus €45-60k for an SC-200 SOC analyst with the same seniority (APEC + Hays IT Salary Guide 2026 + LinkedIn/Welcome to the Jungle postings for 'Azure Security Engineer' vs 'Microsoft SOC Analyst'). The gap comes from the scarcity of cloud + security engineers and the perceived value of BUILD over RUN.
Azure Security Engineer Associate (AZ-500)
You want to pass both for a complete 'end-to-end Azure Blue Team' profile.
Recommended order: the SC-200 FIRST (fewer Azure prerequisites, you start working with Defender/Sentinel quickly), then the AZ-500 6-12 months later once you have a foothold in Azure and want to cover the BUILD side. The reverse also works (AZ-500 then SC-200) if you come from engineering; the point is that your first cert should be the one where you have the most daily context, so you're not just cramming.
