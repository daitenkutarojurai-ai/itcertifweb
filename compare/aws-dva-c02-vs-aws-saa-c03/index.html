Pour qui chacune ?

AWS Solutions Architect Associate

Amazon AWS · SAA-C03
Tu vises un rôle Cloud Engineer, Architect, Consultant, Pre-sales, Platform Engineer ou DevOps. C'est la cert AWS par défaut.
  • La cert AWS la plus demandée — apparait dans 3x plus d'offres FR que la DVA (LinkedIn 2026).
  • Salaire médian senior 65k€ en France, 70k€ au Luxembourg (Hays/APEC 2026).
  • Couvre largement : compute, storage, réseau, sécurité, coût, DR — base solide pour SAP-C02 ensuite.
  • Reconnue par les ESN, les cabinets de conseil et les équipes plateforme — peu importe ton rôle exact.
  • Surface très large — ~150h d'étude pour vraiment maîtriser les 5 domaines.
  • Questions souvent 'choisis la moins mauvaise architecture' — interprétation pénible.
  • Très peu de code / SDK — si tu es dev, c'est frustrant.

AWS Certified Developer Associate

Amazon AWS · DVA-C02
Tu es développeur backend ou full-stack qui pousse déjà du code sur AWS (Lambda, ECS, App Runner) et tu veux formaliser ce que tu fais.
  • Focus sur les services dev/serverless : Lambda, API Gateway, DynamoDB, SQS/SNS, Step Functions, X-Ray, ECS/EKS.
  • Plus de code et de SDK — questions concrètes sur boto3, IAM policies, environment variables, deployment pipelines.
  • Préparation plus courte (~130h) — moins de surface que la SAA, plus de profondeur sur le runtime.
  • Excellent CV pour les rôles backend cloud-native, FaaS, ou DevOps orienté CI/CD.
  • Reconnaissance employeur plus étroite — beaucoup de recruteurs FR ne savent pas qu'elle existe.
  • Salaire médian comparable à un dev backend sans cert (~52-58k€ senior FR) — le ROI cash est plus faible que la SAA.
  • Si tu n'utilises pas Lambda/DynamoDB au quotidien, certaines questions deviennent du bachotage pur.
  • Ne te projette pas naturellement vers la SAP-C02 (Pro Architect) — la suite logique est la DevOps Pro (DOP-C02).
