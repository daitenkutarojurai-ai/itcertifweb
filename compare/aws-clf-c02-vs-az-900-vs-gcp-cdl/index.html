Pour qui chacune ?

AWS Certified Cloud Practitioner

Amazon AWS · CLF-C02
Tu vises une carrière cloud large ou le freelance — AWS reste le pari le plus sûr.
  • AWS a le plus gros vivier d'offres cloud en France — le pari le plus large.
  • Reconnue partout : ESN, conseil, freelance, grands comptes.
  • Chemin balisé vers SAA-C03 derrière, avec énormément de ressources gratuites.
  • Examen à 100$ — le ticket d'entrée le moins cher des trois.
  • QCM purement conceptuel — ne prouve aucune compétence pratique.
  • AWS perd un peu de terrain face à Azure dans les grands comptes FR.
  • ~40h d'étude tout de même pour un examen 'fondamental'.

Microsoft Azure Fundamentals

Microsoft Azure · AZ-900
Ton employeur ou ta cible est une banque, une administration ou un grand groupe — l'Azure y est roi.
  • Azure domine les grands comptes, banques et le secteur public français.
  • Intégration naturelle avec Microsoft 365, déjà présent partout en entreprise.
  • Examen accessible — tremplin direct vers AZ-104 Administrator.
  • Reconnaissance immédiate en interne si ton employeur est Microsoft-shop.
  • Écosystème Azure qui bouge vite — renommages fréquents de services.
  • Valeur surtout forte si l'employeur (ou la cible) est déjà sur Azure.
  • Comme CLF, c'est du conceptuel — pas de preuve de pratique.

Google Cloud Digital Leader

Google Cloud · Cloud Digital Leader
Tu es dans un rôle non-technique (commercial, avant-vente, chef de projet) ou tu vises une boîte data / startup GCP.
  • Pensée pour les profils non-techniques — vocabulaire et cas d'usage business.
  • GCP est fort en data / ML et chez les startups tech.
  • Bon socle pour dialoguer avec des équipes cloud sans être ingénieur.
  • Examen accessible, orienté décision plutôt que configuration.
  • Part de marché GCP plus faible en France — moins d'offres d'emploi.
  • Ce n'est pas un tremplin technique direct (contrairement à CLF → SAA).
  • Peu reconnue comme cert 'CV technique' par les recruteurs FR.
