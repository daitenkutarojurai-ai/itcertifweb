Who is each one for?

Certified Kubernetes Administrator

CNCF / Linux Foundation · CKA
You're targeting Platform Engineer, SRE, or DevOps with cluster responsibility. You'll be the one debugging at 3 a.m.
  • The reference Kubernetes cert for ops / SRE / Platform Engineer roles.
  • Senior median salary of €72k in France, €70k in Belgium, €88k in Luxembourg (Hays 2026).
  • Hands-on format (live lab) — no multiple-choice cramming, you do real k8s work.
  • Covers the whole cluster: control plane, etcd, networking, troubleshooting, security.
  • Very technical — you need to be able to debug a broken cluster in 30 minutes.
  • $395 for the exam, ~80-120 hours of realistic prep if you haven't run a cluster.
  • Heavy time pressure (2 hours for ~15-20 tasks in the terminal).

Certified Kubernetes Application Developer

CNCF / Linux Foundation · CKAD
You're a developer (Go, Java, Python, Node) who deploys to K8s regularly. You want to master the developer side without becoming a cluster admin.
  • More approachable than the CKA — focused on Pods / Deployments / Services / ConfigMaps, not the control plane.
  • Perfect for backend developers who deploy their code on K8s.
  • The same hands-on format as the CKA, but with developer tasks (create a Pod with an init container, expose a Service, etc.).
  • A strong résumé signal for cloud-native developer roles (backend, microservices).
  • Less recognized than the CKA in pure ops/infra — a Platform Engineer role wants the CKA, not the CKAD.
  • Same price as the CKA ($395) for a cert perceived as 'easier'.
  • Only covers the application layer: if you want to manage a cluster, it's the wrong cert.

The verdict, by profile

Not a ranking — each profile has a cert that fits it better. Find yours.

You're a Platform Engineer, SRE, or DevOps engineer responsible for a production cluster.
The CKA covers the control plane, etcd, cluster troubleshooting, networking and security. It's your cert. The CKAD doesn't qualify you for these roles.
Certified Kubernetes Administrator
You're a backend developer deploying your services on Kubernetes.
The CKAD tests exactly your daily work: creating Deployments, configuring ConfigMaps/Secrets, exposing Services, managing liveness/readiness probes. The CKA would be overkill.
Certified Kubernetes Application Developer
You're targeting a Cloud Architect / Platform Lead role.
At lead level, you're expected to manage a cluster end to end. The CKA is expected; the CKAD alone is seen as insufficient.
Certified Kubernetes Administrator
You're new to Kubernetes and torn between the two.
Start with the CKAD: a gentler learning curve, focused on the concepts you'll use every day as a developer. The CKA will come naturally afterward if you drift toward ops.
Certified Kubernetes Application Developer
You're aiming for the CKA + CKAD + CKS (Security) trifecta.
If you're taking all 3, do the CKA first: it gives you the cluster foundations the CKS assumes. The CKAD can follow as a complement within 2-3 months.
