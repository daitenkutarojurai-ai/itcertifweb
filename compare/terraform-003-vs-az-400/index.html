Pour qui chacune ?

HashiCorp Terraform Associate (003)

HashiCorp · Terraform-003
Tu vises DevOps / Platform Engineer / SRE multi-cloud. Tu veux la cert IaC qui te suit partout.
  • La cert IaC de référence — Terraform est le standard de facto en 2026 (multi-cloud, multi-provider).
  • Examen pas cher (70$) et préparable en 30-50h si tu as utilisé Terraform en prod.
  • Cloud-agnostique : t'ouvre AWS, Azure, GCP, Kubernetes, et tous les SaaS modernes (Datadog, Cloudflare, etc.).
  • Salaire médian DevOps senior en France 65k€, Luxembourg 85k€ (Hays 2026).
  • Ne te qualifie PAS sur les autres composants DevOps : CI/CD, monitoring, sécurité pipeline, secret management.
  • Cert seule (sans expérience pratique Terraform en prod) peu valorisée — c'est moins reconnu que 'tu as déployé en prod'.
  • L'exam 003 met l'accent sur Terraform Cloud / Sentinel — si tu n'as utilisé que Terraform OSS, ~15-20% de surprise.

Microsoft Azure DevOps Engineer Expert (AZ-400)

Microsoft Azure · AZ-400
Tu es déjà sous Azure (AZ-104/AZ-204 acquis) et tu vises un poste DevOps senior dans un environnement Microsoft.
  • Couvre tout l'écosystème DevOps Azure : Azure DevOps (Pipelines, Boards, Repos), GitHub Actions, monitoring, security, gouvernance.
  • Niveau Expert (cert avancée) — meilleure prime salariale (~10-15k€ vs Associate-level).
  • Reconnu dans les entreprises Microsoft-lock (banque, public, grandes industries).
  • Combine bien avec AZ-104 + AZ-204 pour un profil 'Azure full-stack'.
  • Prérequis : avoir l'AZ-104 ou AZ-204 déjà passé — sinon, étude beaucoup plus longue.
  • Très Azure-centré : peu transférable hors écosystème Microsoft.
  • 165$ examen + ~100-150h de prep (cert Expert).
  • L'examen évolue régulièrement avec les changements GitHub / Azure DevOps.
