Who is each one for?

HashiCorp Terraform Associate (003)

HashiCorp · Terraform-003
You're targeting multi-cloud DevOps / Platform Engineer / SRE roles. You want the IaC cert that follows you everywhere.
  • The reference IaC cert — Terraform is the de facto standard in 2026 (multi-cloud, multi-provider).
  • A cheap exam ($70) you can prepare in 30-50 hours if you've used Terraform in production.
  • Cloud-agnostic: it opens AWS, Azure, GCP, Kubernetes, and every modern SaaS (Datadog, Cloudflare, etc.).
  • Senior DevOps median salary of €65k in France, €85k in Luxembourg (Hays 2026).
  • Does NOT qualify you on the other DevOps components: CI/CD, monitoring, pipeline security, secrets management.
  • The cert alone (without production Terraform experience) is valued little — it counts for less than 'you've shipped to production'.
  • The 003 exam emphasizes Terraform Cloud / Sentinel — if you've only used open-source Terraform, expect ~15-20% surprises.

Microsoft Azure DevOps Engineer Expert (AZ-400)

Microsoft Azure · AZ-400
You're already on Azure (AZ-104/AZ-204 in hand) and targeting a senior DevOps role in a Microsoft environment.
  • Covers the whole Azure DevOps ecosystem: Azure DevOps (Pipelines, Boards, Repos), GitHub Actions, monitoring, security, governance.
  • Expert level (advanced cert) — a bigger salary premium (~€10-15k vs Associate level).
  • Recognized at Microsoft-committed organizations (banking, public sector, large industrials).
  • Pairs well with the AZ-104 + AZ-204 for a 'full-stack Azure' profile.
  • Prerequisite: you must already hold the AZ-104 or AZ-204 — otherwise, much longer study.
  • Very Azure-centric: transfers poorly outside the Microsoft ecosystem.
  • $165 exam + ~100-150 hours of prep (Expert cert).
  • The exam changes regularly with GitHub / Azure DevOps updates.
