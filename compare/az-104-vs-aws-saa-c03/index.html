Pour qui chacune ?

AWS Solutions Architect Associate (SAA-C03)

Amazon AWS · SAA-C03
Tu vises Cloud Engineer / SA chez une boîte tech-native ou une ESN cloud. Marché EU le plus large.
  • Plus grand marché cloud en France et globalement (~32% du marché cloud public 2025).
  • Salaire médian senior 65k€ en France (Hays/APEC 2026).
  • Écosystème de formations le plus mature : ACG, Stéphane Maarek, Tutorials Dojo.
  • Reconnu chez 100% des entreprises tech-natives + ESN cloud.
  • Examen technique exigeant — 65 questions, beaucoup de scenarios complexes.
  • Demande ~120h de prep avec hands-on; sans labos AWS Free Tier, échec probable.
  • Plus focus 'architecte' (trade-offs) qu'admin (opérations quotidiennes).

Microsoft Azure Administrator Associate (AZ-104)

Microsoft Azure · AZ-104
Tu vises une entreprise traditionnelle (banque, assurance, industrie, secteur public) ou tu viens d'un background Windows/sysadmin.
  • Marché Azure très fort dans la banque, l'assurance, le secteur public en EU (héritage Microsoft).
  • Salaire médian senior 60k€ en France, 78k€ au Luxembourg (Hays 2026).
  • Plus orienté opérations quotidiennes (déployer, configurer, monitorer) — pratique pour sysadmins en reconversion.
  • Microsoft Learn (officiel) est gratuit et excellent — pas besoin de bootcamp payant.
  • Moins valorisé que la cert AWS chez les startups/scale-ups tech-natives.
  • Le tronc Microsoft (Active Directory, Entra ID) est moins transférable hors Azure.
  • 165$ examen + écosystème Microsoft (PowerShell + Azure CLI) à apprendre si pas familier.
