AZ-104 vs AZ-204: Azure Admin or Developer?
Azure cloud admin or Azure cloud developer: which Microsoft Associate to target in 2026

A straight, no-fluff comparison — decide in 5 minutes which one fits your profile.

Reviewed 2026-05 2 certifications 10 profiles analyzed
TL;DRAZ-104 if you don't know which role to target, you're aiming for Azure admin/architect/ops, or you're moving from a sysadmin job — it is the default Azure cert, better paid and more widely recognized. AZ-204 only if you're already a backend developer (.NET/Node/Python) shipping cloud-native code on Azure (App Service, Functions, Cosmos) and want to formalize that skill.

Who is each one for?

Microsoft Azure Administrator

Microsoft Azure · AZ-104
You're targeting Cloud Administrator, Platform Engineer, Azure Cloud Ops or Azure SRE roles, or moving a sysadmin/network job onto Azure — a role where you configure and operate the platform every day.
  • By far the most in-demand Azure cert — roughly 2.5x more job postings than the AZ-204 (LinkedIn / WTTJ France, 2026).
  • Senior median salary of €60k in France, €75k in Luxembourg (Hays/APEC 2026) — the best employability in the Azure Associate lineup.
  • The natural prerequisite for the AZ-305 (Solutions Architect Expert) — about 60% of the content reappears in more depth.
  • Covers identity (Entra ID), networking (VNet, NSG, peering), storage, compute and monitoring — a solid base for every Azure ops role.
  • A very wide surface (identity, governance, networking, storage, compute, backup, monitoring) — ~150 hours to truly master it.
  • No application development: if you want to code on Azure (Functions, App Service, Cosmos), the AZ-204 remains essential.
  • The Portal case-study questions are sometimes pedantic about exact portal labels (RG, PIP, vNICs, etc.).
  • An ops / infrastructure exam — not a fit for developers who want to stay at the application layer.

Microsoft Azure Developer Associate

Microsoft Azure · AZ-204
You're a backend developer (.NET, Node, Python) already shipping code on Azure (App Service, Functions, Cosmos), or you want to formalize your move into cloud-native development.
  • The only Microsoft Associate that validates cloud-native developer skills on Azure: App Service, Functions, Cosmos DB, Service Bus, Event Grid, Key Vault, Container Apps.
  • Highly valued at consultancies delivering .NET / REST APIs on Azure — often requested for senior Azure backend developer engagements.
  • 100% multiple choice + case studies — no graded lab, so less technical stress on exam day.
  • Very useful for the AZ-400 (DevOps Engineer Expert): half the content (CI/CD, Functions, App Service, Key Vault) overlaps.
  • Employer recognition about 2.5x narrower than the AZ-104 — many recruiters don't distinguish the AZ-104 from the AZ-204 and default to the former.
  • Median salary comparable to a senior .NET developer without the cert (~€55-60k in France) — the AZ-204 alone doesn't raise an experienced developer's salary.
  • Implicit prerequisite: being comfortable in C#/.NET or Node.js already — the cert doesn't teach the language.
  • Not the natural path to the AZ-305 (Architect Expert) — the logical next step for developers is the AZ-400 (DevOps).
