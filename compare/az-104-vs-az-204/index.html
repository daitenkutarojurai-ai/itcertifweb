Azure Administrator (AZ-104) vs Azure Developer Associate (AZ-204)
Admin cloud Azure ou dev cloud Azure : quelle Associate Microsoft viser en 2026

Comparatif clair, sans bullshit — décide en 5 minutes laquelle correspond à ton profil.

Révisé 2026-05 2 certifications 10 profils analysés
TL;DRAZ-104 si tu ne sais pas quel rôle viser, si tu vises admin/architect/ops Azure, ou si tu migres d'un poste sysadmin — c'est la cert Azure par défaut, mieux payée, plus reconnue. AZ-204 seulement si tu es déjà développeur backend (.NET/Node/Python) qui livre du code cloud-native sur Azure (App Service, Functions, Cosmos) et que tu veux formaliser cette compétence.

Pour qui chacune ?

Microsoft Azure Administrator

Microsoft Azure · AZ-104
Tu vises Cloud Administrator, Platform Engineer, Cloud Ops Azure, SRE Azure, ou tu migres ton métier sysadmin/réseau vers Azure — un rôle où on configure et opère la plateforme au quotidien.
  • Cert Azure de loin la plus demandée — environ 2,5x plus d'annonces FR que l'AZ-204 (LinkedIn / WTTJ 2026).
  • Salaire médian senior 60k€ FR, 75k€ Luxembourg (Hays/APEC 2026) — meilleur taux d'employabilité de la gamme Associate Azure.
  • Pré-requis naturel pour AZ-305 (Solutions Architect Expert) — 60% du contenu se retrouve approfondi.
  • Couvre identité (Entra ID), réseau (VNet, NSG, peering), stockage, compute, monitoring — base solide pour tous les rôles Azure ops.
  • Surface très large (identité, gouvernance, réseau, stockage, compute, backup, monitoring) — ~150h pour vraiment maîtriser.
  • Pas de développement applicatif : si tu veux coder sur Azure (Functions, App Service, Cosmos), l'AZ-204 reste indispensable.
  • Les questions case-study Portal sont parfois pédantes sur les libellés exacts du portail (RG, PIP, vNICs, etc.).
  • Examen orienté ops / infrastructure — pas adapté aux profils dev qui veulent rester sur la couche applicative.

Microsoft Azure Developer Associate

Microsoft Azure · AZ-204
Tu es développeur backend (.NET, Node, Python) qui livre déjà du code en Azure (App Service, Functions, Cosmos) ou qui veut formaliser une montée en compétence cloud-native côté code.
  • Seule Associate Microsoft qui valide les compétences dev cloud-native sur Azure : App Service, Functions, Cosmos DB, Service Bus, Event Grid, Key Vault, Container Apps.
  • Très valorisée dans les ESN qui livrent du .NET / API REST en Azure — souvent demandée pour les missions Senior Dev Backend Azure.
  • Format 100% QCM + case-studies — pas de lab noté, donc moins de stress technique le jour J.
  • Très utile pour l'AZ-400 (DevOps Engineer Expert) : la moitié du contenu (CI/CD, Functions, App Service, Key Vault) se recoupe.
  • Reconnaissance employeur 2,5x plus étroite que l'AZ-104 — beaucoup de recruteurs FR ne distinguent pas AZ-104 et AZ-204 et privilégient la première par défaut.
  • Salaire médian comparable à un Dev Senior .NET sans cert (~55-60k€ FR) — l'AZ-204 seule ne pousse pas le salaire d'un dev déjà expérimenté.
  • Pré-requis implicite : être déjà à l'aise en C#/.NET ou Node.js — la cert ne couvre pas l'apprentissage du langage.
  • Pas la voie naturelle vers AZ-305 (Architect Expert) — la suite logique côté dev est plutôt AZ-400 (DevOps).
