# ToolRadar dataset schema

One JSON per "best tool for X" intent. Generated by
`scripts/gen-toolradar-pages.js` into:

- `/tool-radar/<slug>/index.html` — comparison page with ranked
  table + per-tool deep-dive cards + verdict
- `/tool-radar/index.html` — grid index of every category

## Honesty model (READ THIS FIRST)

We do not hands-on benchmark every tool monthly. **Scoring is based
on observable, citable facts** (pricing pages, public docs, G2 /
Reddit review consensus). Each subjective claim must have a source
link or be tagged as opinion in the rendered page.

This is documented in a prominent disclaimer on every page so users
know what they're getting: a structured comparison framework, not a
hands-on lab report.

## Top-level fields

| Field          | Type      | Notes                                                                 |
| -------------- | --------- | --------------------------------------------------------------------- |
| `slug`         | string    | URL slug (matches filename and `/tool-radar/<slug>/`).                |
| `title`        | string    | H1 + index card title.                                                |
| `intent`       | string    | The search intent this page targets (e.g. "Best AI for developers"). |
| `tldr`         | string    | 1-2 sentence summary for the index + page intro.                      |
| `lang`         | string    | Page language: `fr` or `en`. Affects copy in the generator.           |
| `icon`         | string    | Emoji for the index card.                                             |
| `color`        | string    | Hex color for the page accent.                                        |
| `lastReviewed` | string    | `YYYY-MM` — rendered prominently as the freshness pill.               |
| `tags`         | string[]  | 2-4 tags used by the index filter.                                    |
| `criteria`     | Criterion[] | 4-6 evaluation criteria with weights summing to ~1.0.               |
| `tools`        | Tool[]    | 3-6 tools, ranked by computed weighted score.                         |
| `verdict`      | object    | `{ overall: <slug>, conditional: [{ profile, winner: <slug>, reason }] }`. |
| `sources`      | array     | Top-level sources (price-comparison sites, review aggregators).       |
| `disclaimer`   | string    | The honesty disclaimer for this category.                             |

## `Criterion` object

```
{
  "id": "free-tier",
  "label": "Free tier",
  "weight": 0.25,
  "description": "What you can do without paying.",
  "scale": "1 = none, 5 = generous indefinite free tier"
}
```

Weights should sum to ≈1.0 (the generator normalizes if they don't).

## `Tool` object

| Field         | Type      | Notes                                                                |
| ------------- | --------- | -------------------------------------------------------------------- |
| `slug`        | string    | Stable id for anchors / affiliate lookups.                           |
| `name`        | string    | Tool name (e.g. "Cursor", "Claude Code").                            |
| `vendor`      | string    | Vendor company.                                                      |
| `pitch`       | string    | One-line pitch (≤ 80 chars).                                         |
| `pricing`     | string    | Compact pricing summary, e.g. "Free · Pro $20/mo · Team $40/u/mo".  |
| `pricingUrl`  | string    | Direct URL to the pricing page (for verification by users).          |
| `scores`      | object    | `{ <criterionId>: 1..5 }` — must include every criterion's id.       |
| `pros`        | object[]  | `[{ text, source? }]` — `source` is an external URL for citation.    |
| `cons`        | object[]  | Same shape as `pros`.                                                |
| `bestFor`     | string    | One-sentence persona match.                                          |
| `affiliate`   | object?   | `{ url, label, payout?, status }` — `status` is `none / pending / live`.  |
| `verifiedAt`  | string    | `YYYY-MM` — when the pricing + scores were last spot-checked.        |

## Computed score

```
weightedScore = sum over criteria of (criterion.weight * tool.score[criterion.id])
```

Range: 1.0 (worst) to 5.0 (best). Rendered to one decimal.

## Conventions

- **Cite, don't claim.** Every "this is better" claim must link to a
  source. If we can't cite it, the page tags it `(opinion)`.
- **Affiliate placeholders are fine** — `status: "none"` or
  `"pending"`. Never ship a fake/broken affiliate URL.
- **Re-review cadence.** Bump `lastReviewed` and per-tool
  `verifiedAt` every quarter. Stale dates undermine the whole
  category.
- **No "all five-star reviews".** If you rate every tool 4 or 5 on
  every criterion, the page is useless. Spread the scores.
