### Title/description length overflow — still growing, still flagged

- **143 titles > 60 chars** (Google SERP cutoff), up from 141 last week.
- **109 descriptions > 160 chars** (SERP cutoff), up from 96 last week
  (worst offender: `careers/az-305-interview-questions-2026/index.html`
  at 203 chars, unchanged since last audit).

Root cause is unchanged: every content generator in `scripts/gen-*.js`
appends `— CertQuests` (12 chars) to the raw pack/topic name, pushing
titles that were fine before the suffix over the 60-char threshold; the
description generators aren't length-clamped at all. As of this run 143 /
388 = **37% of pages** overflow the title limit — this drift needs a
generator-level fix (cap raw title at 46 chars pre-suffix, cap description
at 155 chars post-truncate-at-word-boundary) rather than a per-file
sweep. Not safe to auto-truncate this run — risks mid-sentence cuts and
losing keywords.
