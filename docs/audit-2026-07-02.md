- **141 titles > 60 chars** (Google SERP cutoff). Systemic — the generated
  content templates append `— CertQuests` (12 chars) which pushes many
  otherwise-fine titles over the limit. Worst offenders:
  `careers/cissp-worth-it-2026/index.html` (70), `careers/ccna-200-301-interview-questions-2026/index.html` (63).

  Worst: `careers/az-305-interview-questions-2026/index.html` (203).

to enforce a 58-char title cap and 155-char description cap at generation
time. Not safe to auto-truncate 141 existing files this run — risks
mid-sentence cuts and losing keywords.
